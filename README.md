# Clima Mundial

Um site de previsão do tempo que permite pesquisar cidades de diferentes partes do mundo e consultar informações meteorológicas.

## Sobre o projeto

O **Clima Mundial** é um projeto desenvolvido para praticar HTML, CSS e JavaScript, explorando o consumo de APIs e a manipulação do DOM.

O usuário pode pesquisar uma cidade, selecionar o resultado desejado e visualizar informações sobre as condições climáticas do local.

## Funcionalidades

- Pesquisa de cidades pelo nome.
- Busca de cidades de diferentes países.
- Exibição da temperatura atual.
- Consulta das temperaturas máxima e mínima do dia.
- Exibição da umidade relativa do ar.
- Probabilidade de chuva.
- Mensagens de erro para pesquisas inválidas ou cidades não encontradas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- [Open-Meteo API](https://open-meteo.com/)

## Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
4. Pesquise uma cidade e selecione um dos resultados apresentados.

É necessária uma conexão com a internet para consultar os dados meteorológicos.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Funções e parâmetros em JavaScript.
- Eventos de clique com `addEventListener()`.
- Manipulação do DOM.
- Requisições HTTP com `fetch()`.
- Promessas com `.then()` e tratamento de erros com `.catch()`.
- Consumo e interpretação de dados JSON.
- Utilização de latitude e longitude para consultar informações meteorológicas.
